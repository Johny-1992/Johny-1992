# 🤖 HumanGoOfficialBot — Telegram + TON + AI

Bienvenue sur **HumanGoOfficialBot**, un bot Telegram intelligent alimenté par l'IA d'OpenAI, et connecté au réseau **TON** (The Open Network). Ce projet a pour objectif de **récompenser automatiquement les utilisateurs** avec des tokens HGO (HumanGo) et de **révolutionner l'interaction humaine dans Web3**.

---

## 🚀 Fonctionnalités principales

- ✅ Distribution **automatique de 10 HGO** à chaque nouvel utilisateur
- 🤝 **Récompenses de parrainage** pour les utilisateurs qui invitent d'autres membres
- 🧠 Réponses IA intelligentes avec OpenAI (GPT-4)
- 🔗 Connexion sécurisée à TON via TonCenter API
- 💬 Intégration Telegram complète
- 🌐 API FastAPI déployée gratuitement avec Render

---

## 🛠 Technologies utilisées

| Composant     | Description                            |
|---------------|----------------------------------------|
| Python        | Langage principal                      |
| FastAPI       | Framework backend/API rapide           |
| Telegram Bot  | Pour les interactions avec les users   |
| TON API       | Pour signer et envoyer les HGO         |
| OpenAI API    | Pour l’intelligence conversationnelle  |
| Render        | Hébergement gratuit de l’API           |
